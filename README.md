# Black Mesa redlines

What people have worked out about the Black Mesa Research Facility as the games and mods build it: what is on each map, what
the games' signs and other sources say about its places and days, and which mods count.

## Contributing

Use bmab, from the Black-Mesa-As-Built repository. It gets these files for you, shows each map, and sends your edits here, as
commits or as a pull request. Anyone can correct any entry.

Nothing from the games is in here, beyond short transcriptions of signs: entries refer to the game files and web pages instead.
